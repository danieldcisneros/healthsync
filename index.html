HealthSync

HealthSync is a personal iPhone app. Once a day it copies its owner's Apple Health data, as one JSON file per day, into a folder in the owner's own Google Drive.

It is built and installed from Xcode for a single person's phone. It is not on the App Store and has no other users.

What it uses

  • Apple Health: read-only access to the data types the owner allows.
  • Google Drive: the drive.file permission, which lets the app create and update only the files it makes itself. It cannot see anything else in the Drive.

There is no HealthSync server. Data goes from the phone straight to the owner's Drive.
