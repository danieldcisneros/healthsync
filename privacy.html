HealthSync

Privacy policy

Last updated October 13, 2026

Who uses HealthSync

HealthSync is a personal app used only by its developer on their own iPhone. It is not distributed to anyone else.

Data the app reads

With permission granted in the Health app, HealthSync reads Apple Health data such as activity, body measurements, heart data, sleep, mindfulness, nutrition and workouts, including workout routes. It never writes to Apple Health.

Where the data goes

The app turns each day's data into a JSON file and uploads it over HTTPS to a folder in the signed-in user's own Google Drive. That is the only place data is sent. There is no HealthSync server, and no analytics, advertising or tracking.

Until a file is uploaded, it waits in the app's private storage on the phone and is deleted after upload.

Google user data

HealthSync asks Google only for basic profile information (to show which account is signed in) and the drive.file permission. That permission lets the app create and update the files it makes itself; it cannot read, change or delete any other file in the Drive. HealthSync's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google data is not shared with anyone, sold, or used for advertising.

Sign-in tokens are stored in the iPhone's Keychain and are used only to talk to Google.

Removing data

Signing out in the app deletes its Google tokens from the phone. Access can also be removed at any time at myaccount.google.com/connections. Exported files stay in the user's Drive until the user deletes them. Deleting the app removes everything it stored on the phone.
